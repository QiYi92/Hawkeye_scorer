# Demo14：实际变形靶环与靶心追踪

Demo14 从原视频中的纸面暗线提取靶环，以采样曲线显示褶皱后的形状。支持全自动初始化和重新检测，不需要人工框选。输出是二维像素位置，未接入厘米测距、落点检测或计分。

## 运行

在 VS Code 直接运行根目录 `14_demo_视频变形靶环标定.py`，或执行：

```bash
.venv/bin/python 14_demo_视频变形靶环标定.py
.venv/bin/python scripts/run_demo14.py --video training_video/video9.mp4
```

根目录入口保留中文配置项，默认 video6、预览缩放 0.75、10 环先验。仅使用现有 OpenCV、NumPy，无需下载模型或连接 OAK。

- 空格：暂停 / 继续。
- `n`：进入暂停状态并前进一帧。
- `o`：切换曲线叠加及局部放大视图。
- `r`：从头重新分析，清空跟踪状态；指定输出时也重写这次运行的输出，保持帧号唯一。
- `q` / Esc / 关闭窗口：退出。

质量优先，逐帧处理不丢帧。预览可能慢于原视频；界面 FPS 表示算法处理速度。保存的视频保留输入帧率，所以播放时仍按原视频时间推进。程序启动会覆盖**显式指定**的输出文件，输入与输出路径不能相同。

```bash
.venv/bin/python scripts/run_demo14.py \
  --video training_video/video6.mp4 --no-preview \
  --output-video output/demo14/video6_overlay.mp4 \
  --output-jsonl output/demo14/video6_points.jsonl
```

`--ring-count` 调整纸面环序先验，`--max-frames` 用于短测，默认 0 表示处理全片。所有相对输入、输出路径相对于项目根目录。

## 图像与追踪逻辑

1. 通过亮度和饱和度寻找白色靶纸，并保存其轮廓；连续三帧确认。椭圆只用于搜索坐标，不作为最终靶环。
2. 靶心优先寻找多阈值一致的深色边缘。反光形成深色月牙时，拟合其支持的局部中心；否则对多阈值分割的实心区域求轮廓质心。标注只绘制实际分割边缘，不绘制拟合椭圆。
3. 在原分辨率靶盘 ROI 中做背景亮度扣除、极坐标重采样和双侧暗线响应，以动态规划寻找每条曲线并进行亚像素细化。先验只限制搜索，不足以使曲线成为实测。
4. 使用 LK 前后向光流、纸面特征的 RANSAC 运动一致性和逐点连续三帧确认。仅将当前暗线支持且时序一致的点标为实测。在检测路径和观测／预测融合后分别检查环序；冲突点清空，并丢弃其确认历史。
5. 仅当纸面整体运动估计可靠时，短时遮挡才可沿光流预测，最长为视频时间 0.5 秒。预测不能刷新实测时间；目标丢失、跳帧、切镜、矛盾证据或不可靠光流会更早隐藏。恢复可见后重新确认。

青色实线是图像支持的环线，绿色是靶纸外沿，黄色是靶心可见边缘；橙色虚线为预测曲线。红色十字表示有当前观测支持的中心，橙色十字表示预测。空白表示未知，并非零坐标。

算法的外观先验针对当前素材：下半画面中的白色地面靶、深色中心、近水平长轴。完整靶盘中偏上方的中心候选优先；靶盘出画时禁用这一完整轮廓先验。并非任意颜色、方向或自重叠靶纸的通用分割模型。

## 导出接口

每个原始视频帧写一行 JSON，帧号从 0 开始。`timestamp = frame_index / fps`，适用于现有恒定帧率素材；不将处理耗时当作视频时间。像素原点在原画面左上角，x 向右、y 向下。缩放、局部放大、标签不改变输出坐标。

| 字段 | 含义 |
| --- | --- |
| `frame_index`, `timestamp`, `image_size` | 原始帧号、秒、`[width,height]` |
| `status` | `searching` / `tracking` / `predicting`；表示靶心状态，不保证所有环线可见 |
| `center` | `point`、`source`、`confidence`；实测时附 `method`：`dark_rim_fit` 或 `filled_contour` |
| `outer_boundary` | 实际靶纸轮廓采样，画面裁切边界置空 |
| `bullseye_boundary` | 当前可见的中心深色轮廓；反光时可能只有月牙状部分 |
| `rings` | 各候选环的 `ring_id`、`candidate_index`、`observed_fraction`、`samples` |
| 每个采样点 | `point: [x,y]` 或 `null`，`source: observed/predicted/unknown`，`confidence: 0..1` |

10 环先验沿用旧 Demo 的几何约定：中心边界对应第 1 环，纸张外沿对应第 10 环，两个边界单独输出；`rings` 保存第 2–9 环的曲线，每条默认 240 个角度采样。此约定不等同于识别纸面印刷数字。环数改变后，内部候选为 2 到 `ring_count - 1`。

`candidate_index` 是搜索槽位而不是已确认编号；只有本帧至少 25% 的采样得到实测支持，才填入 `ring_id`。反光和印刷间断仍可能造成错配，应结合实际图像检查。可信度是启发式质量值，不是经过概率校准的准确率。未知点可信度为 0，不导出 NaN。原图当前支持的轮廓、局部拟合中心也属于视觉估计，并非测量仪器真值。

## 验证与复现

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_demo14*' -v
.venv/bin/python scripts/benchmark_demo14.py --workers 6 --export-example --output output/demo14/final_validation
.venv/bin/python scripts/evaluate_demo14_references.py --validation output/demo14/final_validation
```

完整视频评估按视频保存解码帧数、靶心实测/预测帧占比、环线实测采样占比、处理 FPS、P95 耗时和五个时刻的图像及 JSON。`--export-example` 同时为 video6 保存完整 MP4 和 JSONL 到输出目录的上一级。并发任务中的 FPS 不代表独占运行速度。报告保存 tracker 源码 SHA256，便于核对版本。

**环线实测采样占比**的分母为每帧所有候选环角度采样，包含遮挡、出画和初始化；它不是有真值标注的召回率。实测帧占比也不等于靶心准确率。

参考点位于 `tests/fixtures/demo14_visual_references.json`：13 个视频各取第 7 帧的中心，video6 / 9 / 14 另有稀疏环线点。这些点由助手查看未叠加结果的像素网格图目视选取，估计选点不确定度约 3 像素，**未经独立人工复核**。困难片段的环线参考点没有可信环号。评估同时给出所有可计算距离的中位数和 5 像素内参考点覆盖率，未找到对应实测环时记为缺失。不能据此宣称全片满足“中心 5 像素、环线 3 像素”的精度要求；正式验收仍需独立完整标注。

逐视频结果见 [Demo14 验证记录](demo14_validation.md)。video14 的出画环线参考点检查未达标，当前版本仍有明显漏检。

## 已知边界

严重反光、文字、重叠折叠和遮挡仍可能导致误检或断线。局部环形搜索假设可见曲线围绕中心基本保持嵌套；不适合纸面翻折到环线相交的场景。画面边缘之外与完全遮挡部分无法从单目视频精确恢复。外沿分割会受邻近浅色物体干扰，只有当前证据可靠时才应使用这些坐标。

首版没有训练专用分割模型，也没有三维重建；它是可检查、可导出的二维标定 Demo。
