# Demo15 无人工标注首次触地优化实测（2026-10-29）

默认 fusion 从原视频自动提取运动员、鞋部、背景配准和地面证据，不接收人工正确帧、坐标或落地区域。video33 是本次新增开发／原图复核样例，无人工真值；已有 video18–video23 标注仅用于结果生成后的严格评估。

## video33 的实际变化

| 项目 | 优化前 | 优化后 |
|---|---|---|
| 状态 | 待复核 | 已确认触地估计 |
| 输出帧，从0开始 | 59，1.967秒 | 87，2.900秒 |
| 输出点，原图像素 | `[958,334]`，空中候选 | `[585,556]`，触地帧鞋底精修 |
| 确认帧 | 61 | 92，3.067秒 |
| 落靶分类 | 待确认 | 落靶 |

近期鞋部尺度、预测不确定度和外观关联使第59帧轨迹能够接入第63、64帧的继续下降观测。该候选以 `observed_resumed_descent` 明确淘汰；实际接触附近的普通观测允许跨越最多连续缺失两帧，最终在第87帧定位接触起始，在第92帧完成后续证据确认。输出坐标来自第87帧两尺度原图鞋底分割，不是后续支撑帧的坐标。

已检查第83–91帧原图鞋底序列、第87帧接触截图，以及第92帧主窗口和深度窗口。第86帧鞋部仍在下降，第87帧鞋底达到靶心附近并形成随后短时支撑；结果符合可见首次接触。由于没有人工坐标真值，这属于功能与原图复核，不宣称正式10像素通过，也不作为独立泛化准确率。

六段首次触地帧和落点均与上一轮十环优化结果一致。时间标准6/6通过，五段落靶视频的精确位置与联合标准5/5通过。video19 的精确鞋底精修和完整靶环复核调用均为零；其粗坐标不计入精确位置验收分母。

本次验收使用默认fusion。独立depth模式保留原判定作对照，其候选不代替fusion结果，不据此宣称三个模式都达到同一准确率。

## 补检与耗时

| 视频 | 额外RGB补检调用 | 得到鞋部观测 | 前后普通观测校验后接入 | 补检阶段秒 |
|---|---:|---:|---:|---:|
| video18 | 2 | 1 | 0 | 0.998 |
| video19 | 0 | 0 | 0 | 0.549 |
| video20 | 3 | 0 | 0 | 1.391 |
| video21 | 7 | 0 | 0 | 3.439 |
| video22 | 19 | 2 | 1 | 7.658 |
| video23 | 0 | 0 | 0 | 2.702 |
| video33 | 27 | 2 | 0 | 5.752 |

补检阶段包含基础鞋部检查、条件判断和实际RGB补检，所以零模型调用仍有少量耗时。恢复的鞋部观测不会自动成为可信轨迹：只有前后普通观测共同支持，才允许填补轨迹缺口。video33 的主要改进来自普通观测的轨迹关联与空中候选淘汰；其两处补检观测没有强行并入主轨迹。video22 有一处补检通过前后校验接入。

以上为各段完整新提取中的组件耗时；最终后处理和导出另列在本机报告，未声称是受控环境下新旧算法总耗时差。基础补检与首次触地之后的精确精修分开统计，明确脱靶仍跳过后者。

## 测试与兼容

- Demo15：90项测试通过；Demo13/14：45项测试通过，共135项。
- 覆盖空中停顿及延后继续下降、轨迹截断、未决早期接触不能被跑动替换、鞋部尺度骤变、外观冲突、双脚交叉、两帧漏检、补检不能改变普通观测身份、真实滑动／跑动支撑和起始帧回溯。
- 原图补检没有当前鞋部像素时不能输出点；配准失败清除补检历史；补检不会无限延长缺失预算。
- 深度缺失或异常时仍可根据充分视觉证据确认；草地背景和可用深度参考均不单独证明触地。
- 待确认显示候选区域及候选时间，不展示已确认落点坐标或十字；到达确认帧后才显示确认结果。
- v7缓存包含外观、补检及关联质量，旧v6缓存已验证拒绝；七段完整缓存、输入视频及导出帧数全部校验通过。
- 入口与用户选择的 video33 保持原样，人工标注和历史结果未修改。
