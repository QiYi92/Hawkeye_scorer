## 1. 项目概述

### 1.1 项目背景
滑翔伞定点比赛是国际航空运动的重要赛事，选手需精准降落在指定靶心位置。目前比赛主要依赖电子靶（测量0-22厘米范围）和人工测量（22厘米以上范围），存在效率低、易争议、精度不一等问题。本项目旨在开发一套基于计算机视觉的辅助测量系统，实现对电子靶测量范围外（0.16-5米）选手落点的精确测量。

### 1.2 项目目标
- **技术目标**：开发一套高精度视觉测量系统，测量误差≤1-3厘米
- **成本目标**：开发验证阶段总预算控制在1.5-2.5万元以内
- **时间目标**：3-4个月完成技术验证
- **应用目标**：为中小型比赛和训练提供经济高效的测量方案

### 1.3 系统定位
- **辅助系统**：作为电子靶系统的补充，不替代现有电子靶
- **验证阶段**：侧重技术可行性验证，非最终产品
- **可扩展性**：验证成功后可按需升级为专业比赛系统

class FirstContactDetector:
    def __init__(self, contact_threshold=0.05, min_contact_frames=3):
        """初始化第一落点检测器"""
        self.contact_threshold = contact_threshold  # 接触阈值5cm
        self.min_contact_frames = min_contact_frames
        self.contact_history = []

    def detect(self, frame_sequence, keypoints_sequence):
        """检测第一落点"""
        first_contact = None

        for i, (frame, keypoints) in enumerate(zip(frame_sequence, keypoints_sequence)):
            # 1. 检测脚部关键点
            foot_points = self.extract_foot_points(keypoints)

            # 2. 估计地面高度
            ground_height = self.estimate_ground_height(frame)

            # 3. 计算离地高度
            heights = [point[1] - ground_height for point in foot_points]
            min_height = min(heights) if heights else float('inf')

            # 4. 判断是否接触
            is_contact = min_height < self.contact_threshold

            if is_contact:
                self.contact_history.append({
                    'frame_idx': i,
                    'height': min_height,
                    'foot_points': foot_points,
                    'timestamp': frame['timestamp']
                })

                # 5. 验证是否为稳定接触
                if len(self.contact_history) >= self.min_contact_frames:
                    # 检查连续接触
                    if self.check_continuous_contact():
                        first_contact = self.contact_history[0]
                        break

        return first_contact

class StereoDistanceMeasurement:
    def __init__(self, calibration_params):
        """初始化立体测距类"""
        self.calibration = calibration_params

    def measure_distance(self, left_img, right_img, contact_point_img):
        """测量距离"""
        # 1. 立体校正
        left_rect, right_rect = self.rectify_images(left_img, right_img)

        # 2. 计算视差图
        disparity = self.compute_disparity(left_rect, right_rect)

        # 3. 三维重建
        points_3d = cv2.reprojectImageTo3D(disparity, self.calibration['Q'])

        # 4. 提取接触点的三维坐标
        contact_3d = points_3d[contact_point_img[1], contact_point_img[0]]

        # 5. 计算到靶心的距离
        distance = np.linalg.norm(contact_3d[:2])  # 水平距离

        return distance, contact_3d

    def compute_disparity(self, left_img, right_img):
        """使用SGBM算法计算视差"""
        window_size = 5
        min_disp = 0
        num_disp = 64 - min_disp

        stereo = cv2.StereoSGBM_create(
            minDisparity=min_disp,
            numDisparities=num_disp,
            blockSize=5,
            P1=83window_size2,
            P2=323window_size2,
            disp12MaxDiff=1,
            uniquenessRatio=10,
            speckleWindowSize=100,
            speckleRange=32
        )

        disparity = stereo.compute(left_img, right_img).astype(np.float32) / 16.0

        return disparity

## 5. 测试与验证方案

### 5.1 测试目标
1. 验证系统在0.16-5米范围内的测量精度
2. 验证第一落点判定的准确性
3. 验证系统实时性能
4. 验证环境适应性

### 5.2 测试方法
**5.2.1 静态精度测试**
- 使用标定板在不同已知位置进行测量
- 对比系统测量值与实际值的误差
- 每个距离点测量10次，计算均值和标准差

**5.2.2 动态测试**
- 模拟运动员着陆过程
- 使用不同落地姿态（站立、坐地、摔倒）
- 对比系统判定与人工判定的一致性

**5.2.3 环境适应性测试**
- 不同光照条件（强光、阴天、傍晚）
- 不同天气条件（晴天、多云、小雨）
- 不同地面材质（草地、沙地、泥土）

### 10.1 方案优势

4. **可扩展**：模块化设计，便于后续升级扩展
5. **实用性强**：专注于解决实际比赛中的痛点问题

### 10.2 创新点
1. **专门的第一落点判定算法**：针对滑翔伞比赛特点设计
